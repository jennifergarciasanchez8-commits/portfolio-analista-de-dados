## Projetos

### 1. Análise de dados da Olist — Projeto Final Harve

Projeto final desenvolvido individualmente como conclusão da formação em Analista de Dados da Harve. O projeto simulou um desafio profissional, no qual foi necessário analisar os dados da Olist e responder a quatro perguntas de negócio relacionadas a vendas, clientes, entregas e categorias de produtos.

O desenvolvimento foi realizado de forma completa, desde a exploração e investigação dos dados até o tratamento, modelagem, análise e apresentação dos resultados.

**Ferramentas utilizadas:**

- SQL
- Python e Pandas
- Power BI
- DAX

**Principais etapas:**

- Exploração e investigação dos dados utilizando SQL
- Análise da qualidade e consistência dos dados
- Tratamento e preparação dos dados com Python e Pandas
- Criação de arquivos CSV tratados para análise
- Modelagem dos dados no Power BI
- Criação de medidas e indicadores utilizando DAX
- Desenvolvimento de dashboards para análise das informações
- Análise dos resultados e identificação dos principais insights
- Elaboração das respostas para as quatro perguntas de negócio propostas no projeto

**Resultado:**

Dashboard executivo com indicadores e análises sobre faturamento, clientes, categorias, entregas e avaliações, permitindo uma visão geral dos principais resultados encontrados nos dados.

**Status:** Concluído.

### 2. Análise de dados de um salão de unhas

Projeto pessoal desenvolvido a partir de **dados reais de um salão de unhas**, com o objetivo de transformar informações registradas inicialmente em papel em uma base de dados estruturada para análise do negócio.

O projeto foi desenvolvido desde o início: os dados foram organizados e digitados em uma planilha Excel, estruturados e tratados para permitir a análise de informações como faturamento, serviços realizados, clientes, despesas e desempenho do negócio.

**Ferramentas utilizadas:**

- Excel
- Power Query
- SQL
- Power BI

**Etapas desenvolvidas até o momento:**

- Organização e digitalização dos dados que estavam registrados em papel
- Criação da base de dados no Excel
- Limpeza e padronização das informações
- Organização dos dados de vendas, serviços e despesas
- Criação de tabelas dinâmicas, indicadores e gráficos
- Desenvolvimento de um dashboard no Excel
- Estruturação da base para análise utilizando SQL
- Início do desenvolvimento da análise no Power BI

**Objetivo do projeto:**

Transformar dados reais de um pequeno negócio, inicialmente registrados de forma manual, em informações estruturadas e visuais que possam apoiar a análise do faturamento, dos serviços, das despesas e do desempenho do negócio.

**Status:** Em desenvolvimento.
