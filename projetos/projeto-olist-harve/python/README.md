# Análise e tratamento dos dados com Python

Nesta etapa do projeto, o Python foi utilizado para preparar os dados antes da criação do dashboard no Power BI.

## O que foi feito

- Conexão com o banco de dados MySQL.
- Carregamento dos dados no Python utilizando Pandas.
- Verificação dos valores nulos.
- Conversão das colunas de data para o formato `datetime`.
- Criação da coluna `dias_entrega`.
- Exportação dos dados tratados para arquivos CSV.

## Arquivos

Os arquivos CSV gerados no tratamento foram utilizados posteriormente no Power BI para realizar as análises e criar o dashboard.

O arquivo `produtos_tratados.csv` foi disponibilizado neste repositório como exemplo dos dados tratados.

## Ferramentas utilizadas

- Python
- Pandas
- MySQL
- CSV
- Power BI
